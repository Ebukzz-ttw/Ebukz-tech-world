# EBUKZ TECH WORLD

A simple beginner-level multi-page business website created for the New Horizon HTML, CSS and JavaScript project assignment.

## Pages

- `index.html` - Home page
- `about.html` - Company background, mission, vision and objectives
- `services.html` - List and descriptions of company services
- `contact.html` - Contact details and a validated contact form

## Other project files

- `style.css` - External stylesheet used by all pages
- `script.js` - JavaScript validation for the contact form
- `README.md` - Project documentation

All files are kept together in the same folder. The website does not use images.

## Technologies

- HTML5
- CSS3
- JavaScript

## Features demonstrated

- Semantic HTML structure, headings, paragraphs, links, lists and form elements
- External CSS stylesheet
- CSS Flexbox and CSS Grid
- Responsive layout using a CSS media query
- JavaScript event handling and contact form validation

## How to view the website

Open the project folder and double-click `index.html`. Use the navigation links to visit the other pages. The website can be viewed locally without an internet connection.

## Contact form notice

The contact form checks that all fields are completed and that the email address has a valid format. It is a demonstration form only. It does not send or store messages because no backend or form submission service is connected.

## Publishing

Upload all project files to a GitHub repository and deploy the website using Netlify, Render or another static website hosting service.
